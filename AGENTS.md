# InferSpec

This repo has InferSpec skills installed. Available slash commands:

- `/inferspec-scan` — bulk-infer OpenSpec specs from code + git + docs
- `/inferspec-cap <slug>` — single-cap deep-dive with interactive Q&A

Specs are written to `openspec/specs/<cap>/spec.md`.
See https://github.com/anrylu/infer-spec for docs.
